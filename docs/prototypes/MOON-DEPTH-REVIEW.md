## 配色与层次

三栏使用职责明确的背景色，区分导航、选择与阅读；总览、会话和设置复用相同背景与选中态。

| 用途 | 色值 | 应用 |
| --- | --- | --- |
| 页面底色 | `#111416` | 总览、会话、设置背景 |
| 导航层 | `#171c20` | 左侧导航、顶栏、底部工具栏 |
| 列表层 | `#272e34` | 中栏、仓库列表、会话列表 |
| 阅读层 | `#1c2227` | Diff、提交详情、内嵌提交编辑器 |
| 选中底色 | `#394638` | 导航、文件、提交、会话 |
| 品牌／焦点 | `#96ca69` | 选中标记、焦点、主要提交按钮 |
| 同步／新增 | `#85b894` | 已同步状态、Diff 新增 |
| 远端信息 | `#79b8e1` | 分支、待推送／待拉取、Diff 块标题 |
| 待处理 | `#ddba79` | 工作区改动、等待备份 |
| 失败／删除 | `#ed8590` | Diff 删除 |

辅助按钮使用中性色，减少刷新、Fetch 等动作对内容阅读的干扰。左栏选中用短竖线，中栏用连续竖线，对应右侧当前内容；所有页面使用同一品牌色。提交编辑器以独立嵌入面板区分于文件清单。复用仓库现有深色 Logo 与已安装字体资产，不请求外部资源。
