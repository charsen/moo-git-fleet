Moo Fleet · Interface Palette

两套自有界面配色

一套把品牌设计稿的蓝绿关系搬进界面（Fleet Blue），一套把母品牌 MOOEEN 的青柠绿搬进界面（Mooeen）。两套都是完整 token 覆盖，已随 0.1.32 上线，与 Dark Modern / Monokai / Dark High Contrast 并列为五套可切换主题；本页数值与 src/client/styles.css 中的实际 token 一致。

01 — 色板

Fleet Blue 的底色取自设计稿暗色面板（蓝黑而不是中性灰），交互色用 chevron 的 #2563EB，身份色仍是绿点的 #28BF3F；Mooeen 直接复用官网的 #84AF3F 与 #A8D452。

蓝黑三层底 + 蓝色交互 + 绿色身份。和 logo 的「蓝箭头 + 绿点」同构。

05 — 结论

RECOMMENDED

Fleet Blue 设为默认

  • 和新 logo 同一套色：蓝箭头做主交互，绿点做身份，界面和品牌稿对得上。
  • 蓝色天然承担「链接 / 焦点 / 选中」，绿色就能空出来专管「已同步 / 成功」，语义不再打架。
  • 中性灰的 Dark Modern 当默认已经有点素，换成蓝黑底之后层级更清楚。
ALTERNATE

Mooeen 作为第二套

  • 给习惯 MOOEEN 官网配色的人一个「同一个生态」的连续感。
  • 纯黑底 + 单一青柠强调，长时间盯仓库列表最不累。
  • 青柠 #84AF3F 恰好是升级前那版绿，老用户会觉得眼熟。
一个取舍要提前说清楚：Mooeen 主题里 --color-brand 是青柠 #84AF3F，而 logo 里那个绿点是硬编码的 #28BF3F。也就是说这套主题下「品牌色」和「logo 的绿」不是同一个绿（并排能看出来）。两种处理：接受它——logo 是固定商标，不随主题变；或者给 logo 加一个只在 Mooeen 下生效的 CSS 滤镜把绿点压到青柠，代价是资产失真。建议前者，预览里就是前者的样子。
