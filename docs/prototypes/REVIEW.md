# 三栏仓库工作台：两轮测试与优化

日期：2026-09-30。对象：[独立 HTML 交互稿](repository-workbench.html)。

本轮只修改交互稿，数据全部在浏览器内存中模拟。未接入 Fleet Git API，未读取真实仓库或会话，未构建或安装桌面 App。

## 第一轮：操作与状态

下列问题均先在浏览器复现，再修改并用相同检查复测通过。

| 原问题 | 优化后的行为 |
| --- | --- |
| 点击文件后按钮失去焦点 | 重绘列表后恢复原文件按钮焦点 |
| 勾选文件后复选框失去焦点 | 保留勾选位置与键盘焦点 |
| 顶栏方向键意外切换文件 | 文件导航只作用于文件按钮；搜索框向下进入匹配文件 |
| 切回工作区清空搜索 | 各视图保留搜索、选择与滚动位置 |
| Esc 直接丢失提交说明 | 有草稿时先确认；可继续编辑或明确放弃 |
| 未跟踪文件暂存后仍显示 U | 已暂存区域显示新增 A |

## 第二轮：布局与阅读

下列问题均先在浏览器复现，再修改并用相同检查复测通过。

| 原问题 | 优化后的行为 |
| --- | --- |
| 拖宽左右栏后缩窗，Diff 被挤到约 200px | 窗口变化后重新约束栏宽，右栏至少保留 420px |
| 长代码行把按块操作按钮推出视口 | 修改块标题栏按预览视口定宽，按钮保持可见 |
| 1024px 下代码仅 10px | 提高至 11px；宽屏代码为 12px |
| 900px 高度下已暂存清单大部分隐藏 | 压缩文件行间距，初始示例清单可完整显示 |
| 文件预览不在搜索结果内时没有说明 | 展示范围提示，并提供清除筛选入口 |
| 按块操作后横向阅读位置归零 | 保留横向滚动；切换文件时记住各自阅读位置 |

补充修正了模拟提交完成后的焦点回退：提交按钮禁用后，焦点回到当前文件，便于继续审阅未暂存变化。

## 验证结果与边界

- 两轮定向检查各 6 项通过；补充的草稿恢复、弹窗焦点、模拟提交范围、搜索、Diff 范围键盘操作与视口检查共 12 项通过。
- Chrome 验证 1024×768、1440×900、1920×1080；页面无横向溢出。默认右栏宽度分别为 556、862、1342 CSS px。
- 浏览器运行错误为 0；内联 JavaScript 语法检查与 diff 空白检查通过。
- 上述结果只证明示例交互与布局。真实 Git 身份与竞态保护、Vue 接入、macOS WKWebView 和 Windows/Linux 桌面壳均未在此稿件中验证。

这是设计阶段的验证记录。后续已接入正式 Vue 与 Git 业务，范围及验证结果见[仓库详情工作台](../REPOSITORY-WORKSPACE.md)。
