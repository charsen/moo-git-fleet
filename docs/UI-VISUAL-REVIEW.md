# 界面视觉复查

2026-09-30：按用户要求逐页截图检查窗口利用、字体与滚动体验；随后接入分组全选、五款字体及界面字号设置。

## 范围与变化

- 默认使用系统界面字体，正文常规字重，标题与强调文字统一降低字重；文件清单使用界面字体，代码、SHA 等保持等宽。
- 界面字号以 14 px 为基准；现有文字声明改用相对字号，用户可选 12–16 px，标题、正文、辅助信息同步按比例变化，窗口分栏和断点不缩放。
- 「个人配置与仓库接入 → 界面显示」提供系统字体、IBM Plex Sans、冬青黑体、黑体、宋体，以及恢复默认。沿既有受保护视图偏好 API 自动保存，旧配置保持兼容；系统缺失字体时使用预设替代字体。
- Tag 与 Stash 固定页面标题、创建表单和底部提示，清单占据剩余宽高，保留一个纵向滚动容器。高级分支管理也取消清单内的第二层纵向滚动。
- 全屏详情取消根占位裁切，同时补偿背景宽度，避免返回主界面时跳动。会话抽屉与确认弹窗锁定背景滚动；长会话标题省略显示并为关闭按钮保留空间。
- 提交清单最多直接显示两个 Tag，再显示剩余数量，避免同一提交挂多个标签时挤占清单。
- 未暂存、已暂存标题增加独立三态全选框；搜索时只勾选匹配项，保留隐藏勾选，冲突文件不参与普通全选。勾选只改变选择状态，右侧按钮执行既有暂存操作。
- 修正工作区 Diff 固定行号列的偏移，使代码首字符不被遮挡；首次配置加载不再把默认空表单误认成未保存编辑。

## 2026-10-02 仓库列表截断、圆角刻度与空态文案

逐页复拍 1440×900 与 1024×900 后发现的问题，均为定向修复，未改动 Git 操作语义与交互流程。

### 列表截断与列宽

- 仓库列表「分支」列是唯一没有省略号的单行文本：文字节点直接放进 `white-space: nowrap` 的 flex，靠 `td` 的 `overflow: hidden` 硬裁，例如 `feat-checkout-flow-refactor` 被切成 `feat-checkout-flow-ref`。改为 `branch-name` 子元素承接 `text-overflow: ellipsis`，图标 `flex: none`，并补 `title` 显示完整分支名；upstream 次级行同时补 `title`。
- 「远端」列的 `Fetch 8 分钟前` 需要约 102px 内容宽。11% 列宽在约 1258px 以下放不下，1024px 实测内容宽仅 79px，渲染成 `Fetch 8 …`，分钟与天完全无法区分。≤1360px 把该列提到 12.5%，≤1120px 提到 15%。
- ≤1120px 重排列预算为仓库 21 / 分支 16 / 工作区 7 / 远端 15 / 最近提交 17，状态列继续固定 150px。既让远端放得下时间单位，也让「分支 / UPSTREAM」表头不再折成两行（此前 1024px 下 `th` 高 43px 但文字占两行）。工作区只有 M/U 计数、最近提交本就截断，从这两列各让出 1–3 个百分点。
- 工具栏排序下拉原为 118px，最长选项「有动静优先」需要约 126px，默认状态即显示成「有动静优…」。默认与 ≤1360px 两档都改为 136px。
- 行内次级间距统一到 6px 节奏（名称行、次级行、计数组原为 5/7px 混用）。

### 圆角刻度

- 新增 `--radius-xs/sm/md/lg/pill` = 4/6/8/10/999，替换 `styles.css` 中原先散落的 3/4/5/6/7/8/9/10/12px。同类元素不再落在不同档位：表单输入 5px 与相邻下拉 6px 的错位、三个弹窗 9px 与设置弹窗 10px 的错位、面板/弹层 7px 与 8px 的错位都已消除。
