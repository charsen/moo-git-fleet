## 2026-10-02 操作体验：静默失败、键盘流与后台 inert

按「操作体验」复查前端交互层，逐项在隔离环境复现后再改。以下每条都做过浏览器实测，未验证项单独列出。

### 修复的静默失败

- **「移出工作台」失败时界面毫无反应**：`removeRepository` 没有 `try/catch`、没有忙碌态，请求失败时 rejection 无人接管——弹窗没关、仓库还在、像没点过。补 `repositoryRemovalBusy`（在途时禁用 + 转圈 + 重入保护）、成功提示与失败提示。用拦截 `DELETE /api/repositories/:id` 的失败请求实测：在途时按钮 `disabled` 且出现 spinner，失败后抽屉内的反馈条显示「连不上 Moo Fleet 本地服务…」，仓库仍在列表中。
- **「清理缺失仓库」在途可重复点击**：有错误处理但没有忙碌态，慢请求期间可以再点出一次确认。补 `pruneBusy` + 禁用 + spinner。实测把隔离夹具目录移走后触发该告警：在途时按钮禁用且转圈，完成后告警消失并提示「已清理 1 个路径缺失的仓库」。
- **重命名分支时按 Esc 连关两层**：输入框的 `@keydown.esc` 没 `.stop`，事件冒泡到面板的 `@keydown.esc.stop.prevent`，结果是「取消重命名」顺带关掉整个分支面板。改成 `.stop.prevent`；现在一次 Esc 只回到分支列表，再按一次才关面板。

### 修掉的键盘死路

- **点了「重命名」光标不在输入框里**：重命名输入框在 `v-for` 里，模板 ref 会解析成数组，`branchRenameInput.value?.focus()` 抛 `is not a function`（实测捕获到该 unhandled rejection）。改为按面板范围查一次 DOM 再聚焦，并删掉这个永远拿不到元素的 ref。
- **可搜索下拉回不到搜索框**：用 ↓ 进入选项后，↑ 会绕到最后一项，Shift+Tab 直接关掉整个菜单。现在第一项再按 ↑ 回到搜索框，Shift+Tab 也回到搜索框且菜单保持打开。
- **全局 Tab 陷阱会覆盖局部处理**：`trapDialogFocus` 不看 `defaultPrevented`，把局部刚移好的焦点又挪走（表现为上面那条 Shift+Tab 失效）。现在局部接管过的 Tab 直接判定为已处理。
- **管理分支面板的 Tab 会关掉面板**：面板是 `role="dialog"`，但焦点一离开 `.branch-menu`，`handleBranchMenuFocusOut` 就关面板。改为面板内局部循环 Tab（不走全局焦点层，避免关闭时把焦点硬拉回触发按钮），并用 ↑/↓ 在本地分支之间移动。实测连按 8 次 Tab 焦点仍在面板内、面板未关闭；↑/↓ 在可用分支间往返正常。
- **会话清单没有行导航**：仓库列表有 `J`/`K`，会话页按什么都没反应。补 ↓（搜索框进入清单）与 ↑/↓（行之间移动），仓库行也补上 ↑/↓，让所有清单的方向键语义一致。
- **快捷键帮助不分工作区**：会话页也列出 `H`、`J`/`K`、`Enter`、提交与阅读快捷键这些在那里按了没反应的键。改为按 `activeWorkspace` 出两套列表，「在仓库行之间移动焦点」同时列出 `J K` 与 `↑ ↓` 两组可选键。
- **分隔条只有 ← / → 与 Home**：补 `End` 拉到当前窗口允许的最宽，并在分隔条 `title` 里写明三个键。分支栏与文件栏是左右并列的竖向分隔条，按 `aria-orientation="vertical"` 与既有 README 口径继续用 ← / →，没有改成 ↑/↓。

### 后台 inert

- 有焦点层打开时，被遮住的后台内容对读屏和脚本都不应可达。`.topbar`、`main.workspace`、跳转链接与 `SessionRelay` 根节点按需置 `inert`；会话页自己的抽屉/确认/备份设置都 Teleport 到 body，所以在组件内部对本页根节点置 inert（`backgroundInert` prop 叠加 App 层）。
- 实测：无弹层时三者 `inert` 均为 false；打开仓库抽屉后 `.topbar`/`main.workspace`/跳转链接为 true、抽屉自身为 false；关闭后恢复 false，且焦点仍能正常回到原来的仓库行（`inert` 没有破坏 `data-focus-return` 的还焦）。

### 管理配置弹窗的反馈位置

- 弹窗内的操作反馈原本排在长滚动区最末尾，用户停在顶部点「保存」时看不到。`.setup-feedback` 改为贴底 `sticky` 并换成不透明底色。实测在弹窗顶部触发一个真实错误（不存在的扫描目录）：`scrollTop` 仍为 0，反馈条完整落在可视区内且底色不透明。

### 未验证项与边界

- 「清理缺失仓库」的失败分支与成功分支用的是同一套 try/finally，只实测了成功路径；失败路径未单独构造。
- 「移出工作台」的成功路径会真的改配置，未在夹具里跑通，只改了失败路径实测。
- `inert` 的实际读屏效果只做了 DOM 属性断言（无读屏软件），Tab 陷阱与还焦是真实按键实测。
- 类型检查（`vue-tsc` + 服务端 `tsc`）、客户端生产构建、`select-options`/`presentation`/`view-preferences` 三组定向测试通过。本次未跑全量测试，未执行任何 Git 写操作，未重新安装原生 App。
