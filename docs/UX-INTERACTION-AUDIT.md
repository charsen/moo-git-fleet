## 范围与隔离

覆盖仓库接入和总览、工作区和提交、分支和本地模拟远端、历史/文件树/Blame/Reflog、Stash/Tag、冲突、操作记录、会话备份与设置、共享下拉和键盘焦点。使用临时 Fleet / Claude / Codex 三个数据根和测试 Git 仓库；不操作真实用户仓库、会话、凭据或外部远端。1024 / 1440 px 桌面视口。

## 操作弹窗统一与宽度

用户追加反馈：Pull、合并等操作的弹窗风格不一致，合并窗口过窄。新增共享操作弹窗样式层，统一普通 Git 确认窗、合并窗与关联远端窗的标题图标、字体、背景、边框、内边距和底部按钮；危险等级仍使用原有红黄绿语义。

- 普通确认窗从 560 px 调整为 640 px，合并窗从 520 px 调整为 840 px，关联远端窗为 800 px；宽度和高度均保留视口边距。
- 长分支名完整换行；正文独立滚动，标题和底部操作保持可见。Git 执行、预检与确认语义保持原有实现。
- 隔离浏览器实测 Pull、合并和关联远端窗：1024/1440 px 均无横向溢出；合并使用真实长分支名和真实预检结果。Pull 初始焦点在取消，Tab 到确认，Esc 关闭。
- 另在 1024 × 640 px 下对合并预检响应注入 8 个长路径和未跟踪重叠标志，仅测试内容布局：窗口高 576 px，正文产生滚动，底部按钮保持可见；未执行合并。
- 已查看 `output/playwright/dialog-pull-1440.png`、`dialog-merge-1440.png`、`dialog-merge-long-1024.png` 与 `dialog-upstream-1440.png`。本次弹窗修改后重新通过类型检查、512 项完整测试和完整构建；未安装 App。
