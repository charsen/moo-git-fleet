## 建议实施顺序与边界

第一轮先收敛大面积背景、设置正文断层和选中态；第二轮处理 1024 px 布局和列表排版；最后统一弹层与阅读工具条细节。先复用现有语义 token、SelectMenu 和操作弹窗规范，再补必要的共享尺寸；不逐页硬编码独立主题。

保持 Git 红绿差异、警告与危险动作颜色，保留文字对比度、键盘焦点、正文滚动和操作确认。已有暗化的主列表和中栏可作为基准，继续增加层次时优先依赖间距、对齐、细分隔线，避免重新制造大面积明度差。

## 实施与复查

已实施上述视觉范围，仅修改 CSS：

- 统一 `--color-list-muted`，主仓库表、仓库中栏、会话列表、操作记录和批量结果复用约 `#1c2126` 的暗色底。设置正文由整个滚动容器铺色，消除短内容下方的背景断层。
- 内容选中底色降为 `#26302b`，导航另用淡色 token；保留侧线、键盘焦点和 Git 状态色。移除辅助状态光晕，运行中状态仍保留动画。
- 1024 px 顶栏缩为 90 px；会话标题与备份控件分行，搜索/排序/来源筛选重新分配宽度；主表优先保留仓库名称和提交标题，表头不折行，Fetch 时间保留完整单位。复查时修正了窄窗口排序控件与筛选按钮的重叠。
- 提交列表间距收紧，文件标题和对比页签底色靠近阅读区；操作与会话弹窗共用标题字号、图标尺寸和头尾间距，合并来源/目标卡片降低明度。
