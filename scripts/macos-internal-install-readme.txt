Moo Fleet 0.1.27 内测安装说明

适用设备：Apple Silicon 或 Intel Mac，macOS 13.5 或更高版本。请使用与设备架构匹配的 DMG。

推荐安装方式

1. 先退出正在运行的 Moo Fleet。
2. 双击“安装 Moo Fleet（内测）.command”。
3. 如 macOS 拦截脚本，请在 Finder 中右键该脚本，选择“打开”，再确认一次。
4. 如系统要求管理员密码，请按提示授权写入“应用程序”目录。
5. 装完若提示“未能确认本地服务正常”，或应用起来却看不到窗口：把“应用程序”里的 Moo Fleet.app 改名（例如 Moo Fleet-tmp.app）再改回 Moo Fleet.app，然后重新打开。这是本机残留的旧执行记录导致的，改名即可清除。

辅助安装器只会：

- 校验 Moo Fleet 的 Bundle ID、主程序和签名完整性；
- 如果“应用程序”目录已有同名但不同 Bundle ID 的 App，会拒绝覆盖并保留原 App；
- 将 App 安装到 /Applications；
- 复制时不保留 Moo Fleet App 自身的下载隔离属性，包括只读资源文件上的递归标记；
- 使用时间戳目录保留原安装版本，然后启动新版本。

辅助安装器不会关闭 Gatekeeper、不会修改 SIP，也不会重新签名。如提示 Moo Fleet 或后台服务仍在运行，请退出应用、稍等片刻后重试；如提示另一个安装进程正在执行，请等待该安装结束。安装器发送启动请求后会等待最多 20 秒，确认内嵌本地服务实际通过健康检查；未能确认时会自动做一次恢复（结束刚安装这份 App 留下的无响应进程 → 复位应用路径标识 → 重启并再等一轮），仍失败才提示查看 `~/Library/Application Support/Moo Fleet/moo-fleet.log`，且不会撤销已完成的安装。恢复只会结束刚安装这份 App 自己的进程，不会影响其他应用。

**不要用「把 App 拖到 Applications」的方式手动安装。** DMG 经浏览器下载，其中每个文件都会带上系统的下载隔离属性；本 DMG 使用 ad-hoc 签名且未做 Apple 公证，带隔离属性的 App 首次打开会被 Gatekeeper 直接拦下。实测手动拖拽后的副本带 53 处隔离属性、内置运行时无法执行，即使再手动清掉隔离属性也可能仍然起不来（见上面第 5 条的改名办法）。请一律使用辅助安装器。

若坚持手动拖拽并被 Gatekeeper 拦下，可在「系统设置 → 隐私与安全性」里对该 App 选择“仍要打开”；拦下之后再首次启动，仍可能需要上面第 5 条的改名补救。当前 DMG 使用 ad-hoc 签名，仅供可信来源的内部测试；正式公开分发仍需要 Developer ID 签名和 Apple 公证。
